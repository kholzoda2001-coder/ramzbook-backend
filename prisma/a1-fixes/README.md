## Чаро 06 ва 07 худкор нестанд

**06** — номзадҳои худкор барои варианти чорум бад мебароянд:
`«What is the boy's name?»` → номзад `«Name»` (хатои категория).
Варианти нодуруст мазмуни таълимист.

**07** — ҷадвали қоидаи «ту→шумо» дар кӯшиши аввал инро сохт:
```
«Ӯ ЗАН аст.»            → «Ӯ ЗАНЕД аст.»
«She = ӯ — барои ЗАН»   → «… барои ЗАНЕД»
«**You** — ту / шумо»   → «шумо / шумо»
```
«зан», «гир», «рав» ҳам феъли амрӣ, ҳам исманд; тавзеҳи грамматика калимаи
«ту»-ро ҳамчун **мавзӯи таълим** меорад. Скрипт акнун танҳо гузориш медиҳад:
аз 6 дарси омехта танҳо **4 сатр** воқеан ислоҳ мехоҳанд.

## Масъалаи кушода — шакли садои `th`

Дар алифбои тоҷикӣ ҳарфи `th` нест. Ҳозира `03-phonetics.mjs` `тҳ`/`дҳ`
истифода мебарад (ду доимии болои файл). Алтернативаҳо: `th`-и лотинӣ, ё
нигоҳ доштани `с/з` (ки варақаи худи барнома онро манъ мекунад).
**Ин қарори методист аст, на муҳандис.**
